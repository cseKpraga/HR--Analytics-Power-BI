HR Analytics Dashboard (PRDA-03)

Power BI dashboard analysing 22,214 employee records from the HR table (project_hr_analytics database).

Requirements
- Power BI Desktop
- MySQL Connector/NET (needed for the MySQL connection)
- Access to the project_hr_analytics MySQL database

KPIs
- Total employees: 22,214
- Headquarters: 75.25% | Remote: 24.75%
- Average age: 38.4 years

Charts
Hiring rate by year, employees by gender, state, department and race.

Key Insights
- Hiring is steady at about 1,000 people per year
- Gender is close to balanced (50.81% male, 46.46% female, 2.72% non-conforming)
- Ohio, Engineering and White employees are the largest groups
